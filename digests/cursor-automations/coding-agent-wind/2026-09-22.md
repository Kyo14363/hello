   **主張：** 官方稱 4.7 是目前最能扛長任務的 coding／knowledge 模型，價速同 4.6（$2／$6 per M；Fast 加倍）。CursorBench 4.0：46.3%（4.6 為 40.4%）；Terminal-Bench 4.0：38.0%（4.6 為 20.3%）。標準窗 256k、長窗 500k；effort 分 xhigh／high（預設）／medium／low。Cursor 與 Grok Build 即日可用，4.6 仍在。  
   **為什麼值得記：** 這是 9/10 Projects 之後第一則可點的官方產品更新。基準與「最能扛長任務」是第一方數字，還沒有獨立複驗；changelog／@cursor_ai 沒跟上。

2. **來源：** [forum/172527](https://forum.cursor.com/t/share-your-thoughts-on-grok-4-7/172527)（Colin 定價表 16:33Z；kevinn 17:46–18:51Z）＋ [X @SpaceXAI 對照片](https://x.com/SpaceXAI/status/2102069820418048091)  
   **主張：** 官圖把 4.7 **xHigh** 跟 4.6 **High** 並排（staff 承認 4.6 沒跑 xHigh，「benchmark 很貴」）。使用者說每任務 token 幾乎是 4.6 的兩倍，像 sidegrade 不是價值前沿。Grok Bot **沒有 model picker、也不公布現役模型**——4.7 只保證在 Cursor，不保證 Bot 已切。沒有上線促銷；Grok Bot 額度上週五因 Galaxy 直播重置過。  
   **為什麼值得記：** 演示與基準都要打折：xHigh≠High、token 燒更快、Bot 不能當 4.7 驗證面。Composer 2.5 仍被官方定位成日常快模型，但沒上 CursorBench。

   **為什麼值得記：** 池用盡再試新模型，會把 Other Models 也燒光。長窗不是同價升級。
