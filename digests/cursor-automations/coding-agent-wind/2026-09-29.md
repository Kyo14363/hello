2. **來源：** [論壇 173228](https://forum.cursor.com/t/agent-terminal-tool-hangs-forever-on-every-command-even-pwd-after-upgrading-to-macos-27-0-26a428/173228)（Colin 16:46Z；回報者 00:13Z 確認）  
   **主張：** 升到 **macOS 27.0 (26A428)** 後，本機 Agent 連 `pwd`／`echo` 都停在 Running。員工對上 9/21 已提過的根因：macOS 27 **不帶 Rosetta**，PATH 上若還有舊 Intel-only `git`（常見 `/usr/local/bin/git`），agent 查 git 時整條 terminal tool 卡住。`git.path` 只影響 Source Control，**救不了 agent**。Workaround：`file "$(which git)"` 若是 `x86_64`，重裝 Rosetta 或刪掉那份 Intel git（系統 git 在 `/usr/bin/git`）。**3.23** 才會讓「PATH 上的 git 跑不起來」不再吊死 agent。回報者 3.22.7。  
   **為什麼值得記：** 「Agent 連 ls 都不動」先對 `which git` 的架構，不要當模型或 sandbox。現場演示 macOS 27 機器，先跑那一行。
